Seleção 03 · UI Design

Interfaces que sustentam
a estratégia.

Um recorte de interfaces mobile e web que registra minha base hands-on e minha atenção à tradução visual de diferentes negócios.

Escopo
Mobile e web
Prática
UI Design e prototipação visual
Recorte
Arquivo de trabalhos visuais de 2020
O recorte

Interfaces para contextos, públicos e objetivos diferentes.

A seleção reúne uma proposta mobile para busca e avaliação de academias e projetos web de diferentes segmentos. Ela não substitui os cases de processo: funciona como evidência visual da camada de execução que acompanha minha trajetória.

O que evidencia

Hierarquia, consistência e adaptação de linguagem.

  • Organização de informação
  • Fluxos de busca e detalhes
  • Interfaces responsivas
  • Componentes e padrões visuais
  • Adaptação a diferentes marcas
  • Apresentação e mockups

As peças foram preservadas como arquivo de execução visual. Como os materiais originais não incluem métricas, pesquisa ou resultados de negócio, a seleção é apresentada como repertório visual.
